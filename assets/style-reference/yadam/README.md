# 야담 그림체 기준 (단일 계약)

야담의 모든 그림(롱폼 장면, 썸네일 배경, 대표 장면 검사, 야담 쇼츠 CUT)은 이 3장만을 그림체 기준으로 씁니다.
같은 야담 영상의 연속 장면 캡처(휴대폰 스크린샷 2340×1080, 원본 그대로)이며, 계약은 `lib/generative/yadamStyle.ts` 한 곳에 있습니다.
요청에는 `YADAM_REFERENCE_CROP`대로 가공한 1920×800 PNG가 얼굴 근접(capture-2) → 전신(capture-1) → 배경(capture-3) 순서로 들어갑니다
(좌우 여백·하단 자막 제거, 좌상단 "AI" 표시 흐림, 늘리지 않음).
